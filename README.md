# Home Constructors Website Redesign

## Project Overview

This project is a redesign of the Home Constructors website, a construction company based in Soshanguve, South Africa.

I found Home Constructors through Google Maps while searching for local construction companies. After reviewing their existing online presence, I noticed that their website was built using Google Sites and could be improved with a more modern design, better user experience, and a responsive layout.

I redesigned the website using React, JavaScript, Tailwind CSS, and React Router. The goal was to create a professional website that better represents the company's services and makes it easier for potential customers to learn about the business and get in contact.

---

## Technologies Used

- **React** - Used to build reusable website components.
- **JavaScript** - Used to add functionality and control website behaviour.
- **Tailwind CSS** - Used for styling and creating a responsive design.
- **React Router** - Used to navigate between pages without reloading the website.
- **Vite** - Used as the development tool for building and running the project.

---

## Features

- Fully responsive design for mobile, tablet, and desktop screens.
- Modern navigation bar with page routing.
- Hero section with construction images.
- Company introduction section.
- Services section showcasing Home Constructors' services.
- About section explaining the company.
- Contact page for customer enquiries.
- Professional layout designed specifically for a construction company.
- Clean and user-friendly interface.

---

## Pages Included

### Home Page

The homepage introduces Home Constructors and gives visitors an overview of the company. It includes a hero section, company information, and highlights why customers should choose their services.

### About Page

The About page provides more information about the company, its experience, and its role in the construction industry.

### Services Page

The services page displays the different services offered by Home Constructors, including:

- Building and renovations
- Painting services
- Ceiling installation
- Wall and floor tiling
- Paving services
- Electrical services

### Contact Page

The Contact page provides a way for customers to get in touch with the company and request more information.

## Installation and Setup

To run this project locally, follow these steps:

### Clone the repository

```bash
git clone your-repository-link
```

### Open the project folder

```bash
cd company-project-1
```

### Install dependencies

```bash
npm install
```

### Start the development server

```bash
npm run dev
```

The project will run on a local development server.
